# v0.5.5 — Restore Agented chat components + upstream-as-PRs (path B)

**Date:** 2026-05-03
**Milestone target:** v0.5.5 (patch)
**Status:** design awaiting user review

## Context

v0.5.4 shipped a 250-line translation wrapper (path Z) that bridged
the legacy 837-line `AiChatPanel` consumer API to ai-accounts'
vue-styled subcomponents. That was a tactical fix to restore the
silently-broken consumer integration, but it pointed Agented in the
*wrong direction*: composing **inferior** ai-accounts subcomponents
when Agented's own (deleted-in-`b2ee00d`) implementation is the
better one.

User strategy correction (2026-05-03): the project-independent parts
of Agented's chat surface should be **back-migrated to ai-accounts**
as PRs. Agented stops being downstream of inferior code; ai-accounts
gets the upgraded implementation; both projects converge on the
better surface.

## Path chosen: B — restore locally, upstream in parallel

Three readings were considered:

- **A. Restore + audit + upstream-then-consume** — restore Agented's
  components locally; open upstream PRs; v0.5.5 ends here, v0.5.6
  consumes the released upstream. Rejected: leaves Agented rendering
  through the inferior bridge for another patch cycle.
- **B. Restore + upstream + parallel** — restore Agented's components
  to local primary status *now*; open upstream PRs in parallel.
  Translation wrapper from v0.5.4 becomes vestigial and is deleted.
  v0.5.5 ships better UX immediately; v0.5.6 consumes upstream once
  released.
- **C. Different shape entirely** — rejected; user picked B.

**v0.5.5 ships path B.**

## Goal

1. Restore the 8 chat components deleted in `b2ee00d` from
   `b2ee00d~1` git history. Apply mechanical fixes for any 3-week API
   drift in the surrounding codebase.
2. Restore matching test files from `b2ee00d~1` (or write fresh tests
   if originals didn't exist).
3. Delete the v0.5.4 translation wrapper (`AiChatPanel.vue` rewrite +
   31 wrapper-specific tests). The 11 call sites go back to
   consuming the restored Agented `AiChatPanel` directly.
4. Audit each restored component for project-independent vs
   Agented-specific code. Per-component classification, not just
   per-file.
5. For each project-independent component, open a PR against
   `~/Developer/Projects/ai-accounts` that either upgrades the
   existing vue-styled component (e.g., replace ai-accounts'
   `ChatBubble` with Agented's better design) or adds a new one
   (e.g., `CompoundSynthesis`, `AllModeResponses` — already exported
   in vue-styled, but possibly inferior implementations). Each PR
   ships code + tests.

## Non-goals

- **Per-call-site path Y migration.** Call sites stay as-is. After
  restoration they consume Agented's restored `AiChatPanel` directly
  with the same prop set they pass today. v0.5.7+ track for path Y.
- **Backend service reverts.** Commit `3d69ac2 refactor(backend):
  delete inline fan-out chat services, sidecar owns multi-backend
  chat` is a separate concern. If the restored `AiChatPanel` calls
  endpoints the backend deleted, that's a Phase 0 recon item — see
  Risk section. We will *not* revert backend services in v0.5.5
  without explicit re-approval.
- **D-track UX polish per page.** Restoration brings back the
  *previous* UX. Polish past that baseline waits for the
  per-page Y+D milestones (v0.5.6+).

## Phase 0 — Recon (before committing to full scope)

The 8 components were deleted 3 weeks ago. The codebase has moved
since. Restoration risks include:

- Imports referencing files/symbols that no longer exist
  (`useAiChat` was a real composable pre-b2ee00d, now a re-export
  shim around `useSmartChat`)
- Dependencies on backend endpoints that `3d69ac2` removed (inline
  fan-out chat services moved to sidecar)
- Type drift — `BackendDTO`, `Conversation*` types may have changed
  shape
- Test fixtures referencing deleted helpers / mocks

Recon output drives the implementation phase. If recon shows that
restoration requires reverting backend services or rewriting >30% of
each restored component, *flag and pause* — that's a milestone-scale
effort and the user should be re-consulted before committing.

Recon checklist:

- [ ] List every import in each restored component; cross-reference
      against current codebase
- [ ] Check for backend endpoints the restored code expects
      (search Agented's restored code for `/admin/...` paths, then
      check current Litestar routes)
- [ ] Compare `useAiChat` signature pre-b2ee00d vs current
- [ ] Diff Agented's restored `AiChatPanel.vue` against the
      published `@ai-accounts/vue-styled AiChatPanel.vue` so the
      delta is clear (this is the upstream PR's scope)

## Phase 1 — Restoration

For each of the 8 components:

1. `git show b2ee00d~1:frontend/src/components/ai/<file>.vue >
   frontend/src/components/ai/<file>.vue`
2. Run `vue-tsc -b` to surface type errors
3. Apply mechanical fixes (rename moved imports, type-cast where
   shapes drifted, stub deleted helpers temporarily)
4. Run unit tests; restore test files via `git show b2ee00d~1:...`
   if they existed; write fresh if not
5. Verify the 11 call sites still mount cleanly (the call-site smoke
   suite from v0.5.4 carries forward — but each test now mounts
   the *restored* component, not the wrapper)

The translation wrapper from v0.5.4 is deleted in this phase. The
file `frontend/src/components/ai/AiChatPanel.vue` is replaced with
the b2ee00d~1 source; the v0.5.4 test file
`frontend/src/components/ai/__tests__/AiChatPanel.test.ts` is
replaced with whatever existed at b2ee00d~1 plus the call-site
smoke set adapted to the restored shape.

## Risk

- **Phase 0 may surface backend dependencies the user explicitly
  excluded** — `3d69ac2` deleted inline fan-out chat services. If
  restored `AiChatPanel` requires those, restoration cannot proceed
  without backend reverts. Recon flags this; we pause and re-scope.
- **3-week drift** — moved imports, renamed types, deleted helpers.
  Each instance is a localized fix; aggregate may exceed bounded
  patch scope. Mitigation: Phase 0 lists every drift point before
  Phase 1 commits; if drift list >30 items per component, scope down
  to a subset (restore only `AiChatPanel.vue` + its direct
  dependencies; leave the rest for v0.5.6).
- **Upstream PRs may take weeks to release** — dispatch but don't
  block on them. v0.5.5 ships once Agented's local restoration is
  green; v0.5.6 consumes the released upstream when it lands. If
  upstream review surfaces design issues we hadn't anticipated, the
  PR may be reshaped — that's normal.
- **Translation wrapper deletion is one-way** — once v0.5.4's wrapper
  is gone, rolling back to it requires another v0.5.4-style
  rebuilding pass. Mitigation: keep the wrapper file in git history
  (it'll be tagged at v0.5.4); restoration is `git revert` away if
  needed.

   `~/Developer/Projects/ai-accounts` (open, code + tests, awaiting

6. Audit document at `.planning/milestones/v0.5.5/AUDIT.md` lists
