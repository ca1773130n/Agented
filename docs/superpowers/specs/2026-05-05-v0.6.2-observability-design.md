# v0.6.2 — Observability deepening (design)

Three deliverables:

1. **`/admin/metrics` Prometheus endpoint** — admin-gated, emits
   text-format metrics for HTTP request count + status, request
   latency histograms, session-event counts by type, rate-limit
   denial counts.
2. **Slow-request logging middleware** — logs WARN for any request
   over `SLOW_REQUEST_THRESHOLD_MS` (default 500ms).
3. **Frontend session-events viewer page** — admin-only `/admin/
   session-events` reading the v0.5.12 `/admin/auth/session-events`
   API; filterable list view.

## Goals

- Operator can scrape `/admin/metrics` with Prometheus, see
  request rate, p95 latency, error rate, rate-limit denials.
- Slow requests show up in stderr immediately, no scraping needed.
- Operator can browse session events (login/rotation/revoke) via
  the frontend without curl-ing the API.

## Non-goals

- Grafana dashboard JSON exports — operator builds their own.
- Alertmanager rules — operator-defined.
- OpenTelemetry traces. The v0.5.10 traces feature already exists;
  this milestone is metrics + log + UI.
- Per-user analytics dashboard.

## Components

### `app_litestar/metrics.py` (new)

In-memory metric counters + histograms. No external deps; emits
Prometheus text format on demand. Maintained by
`PerformanceMiddleware` (extended to record metrics in addition
to Server-Timing).

Counters:
- `agented_http_requests_total{method,path_prefix,status}` — request count
- `agented_rate_limit_denied_total{path_prefix,key_kind}` — 429s
- `agented_session_events_total{event_type}` — sourced from session_events table

Histograms:
- `agented_http_request_duration_ms{method,path_prefix}` — buckets [10, 50, 100, 250, 500, 1000, 5000, +Inf]

### `app_litestar/routes/metrics.py` (new)

Single route `GET /admin/metrics` guarded by
`requires_role("admin")`. Returns `text/plain; version=0.0.4` with
the Prometheus exposition format. Hits the in-memory metrics
module.

### `SlowRequestMiddleware` (new in `middleware.py`)

Wraps `next_app`; if elapsed > `SLOW_REQUEST_THRESHOLD_MS`, logs
WARN with method, path, duration. Configurable via env var.
Innermost-after-`PerformanceMiddleware` so the timing matches.

### `frontend/src/pages/SessionEventsPage.vue` (new)

Admin-only route `/admin/session-events`. Fetches
`GET /admin/auth/session-events` with optional filters (user_id,
session_id, event_type, limit). Renders a sortable table with
columns: occurred_at, event_type, session_id, user_id, metadata.
