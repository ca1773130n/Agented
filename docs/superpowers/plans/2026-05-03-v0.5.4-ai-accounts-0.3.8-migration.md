# v0.5.4 — ai-accounts 0.3.8 migration (path Z, fat translation wrapper) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the Agented `AiChatPanel` integration with `@ai-accounts/vue-styled` 0.3.8+ by replacing the broken 36-line pass-through wrapper with a translation wrapper that accepts the old 837-line consumer API and drives `useSmartChat` + the published vue-styled subcomponents (`ChatBubble`, `ChatControls`, `ChatInput`, `FinalizationBanner`, `ProcessGroup`). All 11 existing call sites stay unchanged.

**Architecture:** The wrapper composes published `@ai-accounts/vue-styled` subcomponents directly instead of going through `BaseAiChatPanel`. Caller props for `messages` / `streamingContent` / `inputMessage` / backend selectors flow through to the subcomponents; `useSmartChat` is consulted only for backend/account/model option lists and the `resetSession` hook. Messages and streaming are owned by callers — no double state.

**Tech Stack:** Vue 3 (Composition API), TypeScript, `@ai-accounts/vue-styled` (`ChatBubble`, `ChatControls`, `ChatInput`, `FinalizationBanner`, `ProcessGroup`), `@ai-accounts/vue-headless` (`useSmartChat`, `useSmartScroll`, `useAiAccounts`), `@ai-accounts/ts-core` (`BackendDTO`, `BackendOption`, `BackendAccountOption`), Vitest + `@vue/test-utils` + happy-dom.
