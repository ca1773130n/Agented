`{kind, payload, bind, materialize}` endpoint with explicit compensating
cleanup, and the bundle-bind route that consumes 17-03's conn-accepting
`_add_binding`. The codebase has NO transaction/saga abstraction spanning DB +

so atomicity is implemented as ordered LIFO compensation in a service function.

plus the route half of #4 (bundle-bind in one call). Depends on 17-02 (subagent
+ kinds + create fns) and 17-03 (forge_bundles + `_add_binding`).

gold-standard injected-failure no-orphan assertions at TWO stages.

    `remove_project_forge_binding(binding_id)`, then delete the asset row
    (delete_subagent / kind-specific delete). WRAP EACH compensation action in
    its own try/except so a cleanup failure cannot mask the original error; after
    compensation, RE-RAISE the original exception. Return a dict with asset,
    binding, and written paths on success.
