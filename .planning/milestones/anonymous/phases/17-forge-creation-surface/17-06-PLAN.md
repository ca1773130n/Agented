<objective>
Ship the `forge-creator` default bundle and the session-completion auto-import
pipeline:
(a) five global-scope creator skills (skill/rule/hook/command/subagent-creator),
each an agentskills.io-compatible SKILL.md, composed into a `forge-creator`
bundle, seeded idempotently at startup (predefined-bot pattern);
(b) a fourth session-completion handler on the `execution_events` bus that diffs
`.claude/` against the forge manifest, imports session-scaffolded primitives via
`HarnessLoaderService` + the 17-05 atomic API, and records provenance (origin
sha256 content-hash + source session id) in a new `forge_origin` table — but
ONLY auto-binds artifacts from Agented-driven sessions; foreign/operator content
is not imported.

Purpose: success criterion #5. SECURITY (house rule): auto-imported `.claude/`
content is a system-prompt-injection vector across four harnesses; the
Agented-driven-session gate IS the Phase 17 mitigation — foreign-repo content
must NOT auto-bind. Depends on 17-05 (atomic API).

Output: 5 SKILL.md seeds, `forge_creator_seed.py`, `forge_session_import.py`,
migration 157 + `forge_origin.py`, lifecycle registration, two test modules.
Research basis: 17-RESEARCH.md §17-06 + Open Questions 1 & 2 + Security note.
</objective>
