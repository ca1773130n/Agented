<objective>
The quality/safety guard (REQ-25) — three pure-ish functions the gate (22-05) calls
before any auto-apply:
- `scan_skill_content(content) -> ScanResult` — fail-closed scanner for
  prompt-injection, exfiltration, and invisible-Unicode (zero-width + bidi + word-join +
  tag chars). ANY match → unsafe.
- `find_duplicate_binding(name, content) -> existing | None` — name-cosine dedup against
  bound skills (user_skills / project_skills) → patch-over-create.
- `provenance_allows_overwrite(asset_id, kind, on_disk_path) -> bool` — re-hash the
  on-disk SKILL.md and compare to the stored `origin_hash`; divergence means the operator
  modified it → refuse overwrite.
