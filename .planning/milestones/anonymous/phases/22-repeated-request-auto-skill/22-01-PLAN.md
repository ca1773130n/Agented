<objective>
Create the `repeated_request_signals` store — the persistence substrate for the
self-improvement loop (REQ-22). A hash-keyed table whose UPSERT *accumulates*
evidence of recurring user requests: salience grows with repetition rather than
decaying. The gate (22-05) reads `occurrence_count` and `verified_success_count`
from these rows; the detector (22-03) writes them.

Purpose: Give the loop a durable, monotonic count of how often a request recurs,
plus the embedding needed for cosine matching and the provenance bookkeeping
(`skill_created`) needed to avoid re-creating skills.
Output: One schema module, one repo module, one Pydantic model, one test suite.
Research basis: 22-RESEARCH.md — mirror `_project_autonomy.py` / `_harness_takeaways.py`
DDL patterns; store the embedding BLOB the way `agent_memory` does via
`serialize_embedding`/`deserialize_embedding` (embedding_service.py:60,65).
