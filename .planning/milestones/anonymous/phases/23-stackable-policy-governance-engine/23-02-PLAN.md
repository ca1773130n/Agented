<feature>
  <name>Four builtin evaluators + dispatch (SC2)</name>
  <files>backend/app/services/policy_service.py, backend/tests/test_policy_builtins.py</files>
  <behavior>
    Each evaluator has signature `_eval_<kind>(params: dict, action: dict) -> tuple[str, str]`
    returning (decision, reason) where decision in {"allow","deny","ask"}. _eval_row dispatches
    on row["kind"] via _BUILTINS, falling back to the stored `effect` for kind="custom"/unknown.

    cost_budget (params: {max_cost_usd: float, ask_thresholds_usd: list[float]}):
      - spend = action.get("total_cost_usd", action.get("spend", 0.0))
      - spend >= max_cost_usd (and max_cost_usd > 0) -> ("deny", "hard cost cap ...")
      - any t in ask_thresholds_usd where spend >= t -> ("ask", "soft cost threshold ...")
      - else -> ("allow", "within cost budget")
      Cases: spend=0, cap=10, thresholds=[5] -> allow; spend=6 -> ask; spend=12 -> deny.

    max_tool_calls_per_session (params: {max_tool_calls: int}):
      - count = action.get("tool_calls", 0)
      - count >= max_tool_calls (and max_tool_calls > 0) -> ("deny", "tool-call cap ...")
      - else -> ("allow", ...)
      Cases: count=3,max=5 -> allow; count=5,max=5 -> deny.

    ask_on_os_tools (params: {} or {kinds: [...]}):
      - kinds = params.get("kinds", ["shell", "file_write", "process_launch"])
      - action.get("kind") in kinds -> ("ask", "OS tool requires approval: <kind>")
      - else -> ("allow", ...)
      Cases: action.kind="shell" -> ask; action.kind="read" -> allow.

    enforce_sandbox (params: {require_sandbox: bool}) — INERT UNTIL PHASE 24:
      - if params.get("require_sandbox", True) is set AND action.get("sandboxed") is falsy
        AND action.get("kind") in {"process_launch","shell"} -> ("deny", "sandbox required (Phase 24)")
      - else -> ("allow", "sandbox flag stored (inert until Phase 24)")
      Cases: require_sandbox=True, action sandboxed=False, kind=process_launch -> deny;
             same but sandboxed=True -> allow; a non-launch action -> allow.
      IMPORTANT: add a code comment + docstring stating this is the STORE-NOW / ENFORCE-IN-PHASE-24
      flag; no actual sandbox is invoked here.
  </behavior>
  <implementation>

    - test_policy_builtins.py: a focused unit test per evaluator covering the cases above. No DB needed
      for the evaluators themselves (pure functions); use isolated_db only if you also assert via evaluate().
  </implementation>
