<objective>
Create the one reusable sandbox-command-prefix builder for Phase 24. It returns
an argv PREFIX (and a `sandboxed: bool`) to prepend at the single Popen chokepoint
already used by `stdbuf` in `execution_service.py` — NOT a new launcher. Linux uses
`bwrap`, macOS uses `sandbox-exec -p <SBPL>`; where the primitive is missing it
degrades to `(cmd, sandboxed=False)` with a logged warning so the Phase-23
`enforce_sandbox` policy (wired in 24-03) can decide launch-vs-refuse.

Purpose: FS isolation (workspace-only writes) + an egress chokepoint (force all
HTTP(S) through the local proxy from 24-02) with the minimum reversible code.
Output: one module + one deterministic test file (no real sandbox needed in CI).
Research basis: 24-RESEARCH.md Rec 1 (bwrap), Rec 2 (SBPL), Pitfalls 2 & 4.
</objective>
