<objective>
A tiny stdlib `asyncio` deny-by-default forward proxy that governs harness egress.
It reads the cleartext `CONNECT host:443` line (visible even under TLS — no MITM),
checks `host` against a per-session allowlist, and either tunnels bytes or returns
403. This is the L7 egress allowlist of REQ-32; it pairs with the sandbox env
(`HTTPS_PROXY`/`HTTP_PROXY`) from 24-01 so the harness child has exactly one
reachable destination.

Purpose: deny-by-default outbound for autonomous / auto-implement runs without
adding mitmproxy or any dep.
Output: one module + one L2 test (local echo server, ephemeral ports — no real network).
Research basis: 24-RESEARCH.md Rec 3; Pitfall 3 (document env-only as best-effort).
</objective>

      - `class EgressProxy`: holds `allowlist: set[str]`, an optional `on_deny` sink and a

        starts with `CONNECT`, parse `host:port`; else parse absolute-form / Host header.
