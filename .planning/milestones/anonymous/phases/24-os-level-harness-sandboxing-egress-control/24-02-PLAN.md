<objective>
Build the L7 egress allowlist proxy (REQ-32): a tiny stdlib-asyncio deny-by-default forward proxy that gates outbound network for autonomous / auto-implement harness runs. It filters on the cleartext CONNECT host (no TLS MITM, no cert store, no extra dep) — allowlisted host gets a 200 + bidirectional pump, everything else a 403 + a structured deny log. A lifecycle (start on ephemeral port / async stop) and a `proxy_env` helper let Plan 03 inject `HTTPS_PROXY/HTTP_PROXY/NO_PROXY` into the sandboxed child.

Purpose: deny-by-default outbound for the highest-risk runs, the second half of the sandbox (FS isolation from Plan 01 + network isolation here).
